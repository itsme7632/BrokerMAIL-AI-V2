====================================================
WHAT WAS ALREADY DISCOVERED
===========================

1. DELIVERY STATUS BUG

Current behavior:

Emails are marked:

"Delivered to inbox"

immediately after SMTP returns success.

This is incorrect.

SMTP 250 OK only means:

Message accepted by SMTP server.

It DOES NOT mean inbox delivery.

Required fix:

SMTP accepted
→ Status = Accepted

Inbox delivery confirmation
→ Status = Delivered

Open tracking
→ Status = Opened

Do not show "Delivered to inbox" unless actual confirmation exists.

====================================================
2. PREVIEW NOT AVAILABLE
========================

Sent Emails page often shows:

"Preview not available"

Root cause investigation found:

Single Composer emails use:

templateId = 0

Preview endpoint expects a template lookup.

Template lookup fails.

Preview returns empty.

Required fix:

Store complete sent email snapshot:

subject
html body
plain text body
attachments metadata
branding snapshot
template snapshot

Preview must render EXACT email that was sent.

No dependency on template existing later.
