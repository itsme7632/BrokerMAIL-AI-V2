FEATURES TO IMPLEMENT:

1. PRE-SEND VALIDATION

When a CSV/XLSX file is uploaded:

Validate every email address.

Mark as INVALID if:

* Invalid email syntax
* Missing username
* Missing domain
* Invalid characters
* Domain has no MX record
* Domain has no A record
* Domain is on disposable email blocklist

Mark as FLAGGED if:

* info@
* support@
* admin@
* sales@
* contact@
* billing@
* webmaster@

Flagged emails should still be allowed but clearly identified.

2. SUPPRESSION LIST

Create a suppression system.

Whenever a permanent bounce occurs:

* 550 User Unknown
* 550 Mailbox Not Found
* 554 Recipient Rejected
* Similar permanent failures

Automatically:

* Add email to suppression list
* Store reason
* Store timestamp
* Store campaign reference

Future campaigns must never send to suppressed emails.

3. CAMPAIGN REVIEW SCREEN

Before campaign start show:

Valid Leads: X
Invalid Leads: X
Disposable: X
Suppressed: X
Flagged Role Accounts: X

Allow viewing each category.

Only valid leads should be included in campaign sending totals.

4. AUTOMATIC SKIPPING

During campaign creation:

If an email exists in suppression_list:

Skip automatically.

Do not include in send count.

Log:

Skipped: Previously suppressed.

Add a suppression summary:

Last Suppression Date
Top Bounce Reasons
