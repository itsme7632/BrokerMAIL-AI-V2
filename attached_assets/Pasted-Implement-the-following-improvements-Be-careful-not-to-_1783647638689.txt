PART 1 — Deferred SMTP Quota Detection
====================================================

Do NOT modify SMTP authentication, SMTP sending, Nodemailer transport, or campaign logic.

Background:

Our production mail server (cPanel/Exim) accepts emails successfully (250 Queued) and only later sends a Mail Delivery System email such as:

"Domain vertexcarship.com has exceeded the max emails per hour (57/50) allowed. Message will be reattempted later."

The audit confirmed:

• sendMail() succeeds.
• Bounce Scanner later receives the quota notification.
• bounce-scanner.ts never calls smtp-quota.ts.
• isQuotaReachedError() is never used by the bounce scanner.
• Therefore quota recovery never starts.

Required implementation:

1. Reuse the existing quota system.

Do NOT duplicate logic.

Reuse:

- isQuotaReachedError()
- handleMailboxQuotaReached()

There must be a single source of truth.

----------------------------------------------------

2. Extend the bounce scanner.

When processing Mail Delivery System / Mailer-Daemon emails:

• extract the bounce reason
• pass the reason through isQuotaReachedError()

If it returns true:

• call handleMailboxQuotaReached()

using the correct mailbox.

----------------------------------------------------

3. Do NOT suppress recipients.

Quota notifications are NOT recipient bounces.

Do NOT:

• add recipient to suppression list
• mark recipient invalid
• classify as permanent bounce

Only the mailbox should enter cooldown.

----------------------------------------------------

4. Deduplicate.

Continue using processed_bounces.

The same quota email must never trigger cooldown twice.

----------------------------------------------------

5. Preserve existing cooldown.

Continue using the existing implementation for:

• quota_status
• quota_cooldown_until
• quota_probe_count
• recovery scheduler
• automatic resume

Do not implement a second cooldown system.

----------------------------------------------------

6. Logging

Add structured logs.

Example:

[SMTP QUOTA]
Source: BOUNCE_SCANNER
Mailbox: miller@vertexcarship.com
Reason: Domain exceeded max emails per hour
Cooldown: 60 minutes

Also log when recovery succeeds.

----------------------------------------------------

7. Safety

Only trigger quota mode when isQuotaReachedError() matches.

Do NOT trigger cooldown for:

• mailbox full
• greylisting
• DNS failures
• temporary connection issues
• recipient unavailable
